# Adversarial review: "Copilot harness task orchestration.md"

Reviewed: `reports/Copilot harness task orchestration.md` (1,030 lines, all read), `reports/ui-wiring.json` (87 entries), Copilot SDK clone at `b19d3ef043ebfeaeb794339173c39ad6c8eb29ca` (read-only; paths below are relative to `rust/src/`).

Short answer to "is it foolproof?": no. The SDK citations are mostly accurate. The weak parts are the rotation design and the polling and nudge mechanics, which are where tokens get spent. Rotation has six triggers. Only one of them (file size) addresses the crash the spec is trying to prevent, and that one has no live data source as written. Rotation also wakes idle agents, ships a handoff with no size limit, and can disconnect a session that is still busy. No harness in the spec's own prior-art table (Appendix A) rotates on an event count. The 3,000-event trigger is a guess presented as a rule.

Severity: **critical** = will burn tokens or lose or corrupt work in normal operation; **major** = likely bug, race or large waste; **minor** = inconsistency or polish.

## 3. Token-cost model (why the triggers matter)

Per rotation, the new generation pays for: (a) the Copilot system prompt + built-in tool definitions + harness tool schemas (measurable as `system_tokens + tool_definitions_tokens` on `session.usage_info`, `session_events.rs:2431-2449`; not measured by the spec); (b) the handoff (unbounded, F3); (c) a cold prompt cache (`cache_read_tokens` drops to 0; `AssistantUsageData` `session_events.rs:4041-4048`); (d) the model re-reading files it had already read, often the largest cost and invisible to the harness; (e) a forced wake turn if the agent was idle (F5). By comparison, compaction costs one summarisation call (`compaction_tokens_used`) and keeps the system prompt cache-warm.

What is resent every turn: the full tool schema set for the role (14 tools with long JSON schemas for the orchestrator), all `additional_context` fragments already injected (F10), and every digest or handoff that is still in the window.

Recommended minimum trigger set: (1) workspace bytes from `sessions.getSizes` ≥ cap; (2) `compaction_complete{success:false}`; (3) `post_compaction_tokens / token_limit ≥ 0.90`. Before rotating on (2) or (3), try `history.compact` once with harness `custom_instructions`. Always rotate at an idle boundary, and lazily for idle agents.
